== Organisasjonsenhet
[cols="3"]
|===
| https://jira.adeo.no/browse/BEGREP-207[Begrepsdefinisjon] | Oppslag: Kommer | Hendelser: Kommer
|===

*Beskrivelse:* +
Delmengde av en organisasjon som etableres som følge av forhandlinger i medbestemmelsesapparatet. Den har en leder, kan ha ressurser og underliggende organisasjonsenheter.
Begrepet brukes om alle nivåer i hierakiet. For enkelthetsskyld er organisasjonsenhet også forkortet til _enhet_ flere steder i dokumentasjonen.

Team og produktområder er i dag ikke definert som organisasjonsenheter. 
Oppgavekøer, arbeidsbenker og virtuelle enheter er ikke organisasjonsenheter selv om enkelte løsninger i NAV beskriver de som enheter.

*Eksempler:* +
_NAV Familie- og pensjonsytelser Drammen_ er en organisasjonsenhet og har overliggende organisasjonsenhet _Familie- og pensjonsytelser_, og har flere underliggende organisasjonsenheter.

== Organisering

|===

*Beskrivelse:* +
Organisering er den hierarkiske koblingen mellom organisasjonsenheter som danner et hierarki.

== Ressurs
[cols="3"]
|===
| https://data.adeo.no/begrep/BEGREP-14[Datakatalogen] | Oppslag: Kommer | Hendelser: Kommer
|===

*Beskrivelse:* +
Person som utfører oppgaver på vegne av NAV.


*Eksempler:* +
Alle personer som er tilknyttet NAV som ressurs, enten direkte eller gjennom underleverandører.

Omfatter:

* Interne ressurser: Statlig ansatte i NAV, lærlinger og personer på tiltak i NAV, kommunalt ansatte i NAV.
* Eksterne ressurser: Konsulenter, driftspersonell (rengjøring, kantine).

== Kobling
[cols="3"]
|===
|===

*Beskrivelse:* +
Kobling er knytningen mellom en ressurs og en organisasjonsenhet. En ressurs kan flere koblinger samtidig,
og en organisasjonsenhet kan ha kobling med flere ressurser.
Per nå kan ikke en ressurs ha flere koblinger til samme organisasjonsenhet.


*Eksempler:* +
Ansatt Ola har en kobling med organisasjonsenhet 0101000 - Halden

Kodeverk omfatter: +

[%header,cols=4*]
|===
|Felt           |Påkrevd    |Beskrivelse                                                |Eksempel
|Ressurs        |Ja         |Ressursen koblingen gjelder                               |Se ressurs objekt
|Organisasjonsenhet        |Ja         |Organisasjonsenheten koblingen gjelder         |Se organisasjonsenhet objekt
|Gyldig fom     |Ja         |Datoen koblingen blir gyldig                              |2009-01-22
|Gyldig tom     |Nei        |Koblingens siste gyldighets dato                          |2020-02-14, NULL hvis ikke satt.
|===

== Leder
[cols="3"]
|===
|===

*Beskrivelse:* +
Leder er knytningen mellom en ressurs og en organisasjonsenhet. Flere ressurser kan ha lederknyttning mot en organisasjonsenhet, men hvor bare 1 kan være aktiv.
En ressurs kan være leder for flere organisasjonsenheter samtidig.

*Eksempler:* +
Ansatt Ola var leder for organisasjonsenhet 0101000 - Halden i perioden 2018-01-01 til og med 2019-12-01,
Ansatt Heidi tok over som leder fra 2019-12-02.

Kodeverk omfatter: +

[%header,cols=4*]

|Gyldig fom     |Ja         |Datoen leder knyttningen blir gyldig                         |2009-01-22
|Gyldig tom     |Nei        |Leder knyttningen siste gyldighets dato                     |2020-02-14, NULL hvis ikke satt.
