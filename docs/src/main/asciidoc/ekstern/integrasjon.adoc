= Integrasjon

NOM tilbyr integrasjon via GraphQL og Kafka.

== GraphQL

GraphQL kan prøves ut i dev https://nom-api.dev.intern.nav.no/playground[her] (Krever naisdevice eller via utviklerimage).
Det ligger lastet inn pre-utfylte forespørsler som kan bygges videre på.
Skjema kan utforskes ved å gå https://nom-api.dev.intern.nav.no/voyager[her].
