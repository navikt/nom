# Brukergrensesnitt for nom-admin-web

For å bruke npm trenger du ha `node` installert.
Vi anbefaler at du bruker [asdf](https://asdf-vm.com/) slik at du automatisk kjører nødvendige pakker på støttet versjon.
`asdf` vil sette riktige versjoner for diverse pakker som trengs i dette repoet. Se `.tool-versions` i rot-folderen.


## Utvikling

Gå inn i mappene `frackend` og `webapp` og kjør `npm install` for å installere avhengigheter.

```bash
cd frackend && npm install
cd ../webapp && npm install
```

Start frontenden ved å gå til `webapp`-mappen og kjøre `npm run dev`.

```bash
cd app && npm run dev
```

Gå til [https://nom-admin.intern.dev.nav.no/vite-on](https://nom-admin.dev.nav.no/vite-on) for å utvikle lokalt! 🤯
